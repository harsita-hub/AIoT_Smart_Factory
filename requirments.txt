step4.1:Create a data model
 
- Need to tell FastAPI:

“A sensor reading must contain these fields.”

For that, i use Pydantic.

Change  main.py to:
  from fastapi import FastAPI
from pydantic import BaseModel

code is:
app = FastAPI()


class SensorReading(BaseModel):
    machine_id: str
    temperature: float
    vibration: float
    current: float


@app.get("/")
def home():
    return {"message": "AIoT Smart Factory Backend is running"}


@app.post("/api/v1/sensor-readings")
def receive_sensor_reading(data: SensorReading):
    return {
        "message": "Sensor reading received",
        "data": data
    }

The important new part is:

-class SensorReading(BaseModel):

This defines the expected structure of sensor data.

For example, this is valid:
{
    "machine_id": "M001",
    "temperature": 65,
    "vibration": 0.32,
    "current": 4.5
}

But something like this:

{
    "machine_id": "M001",
    "temperature": "hello"
}

will not be accepted correctly because temperature should be a number.

That's called data validation.
